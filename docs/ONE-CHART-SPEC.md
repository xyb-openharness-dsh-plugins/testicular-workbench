## 3. 时间与事件

手术/治疗为独立事件泳道；演示事件有稳定 ID、日期、标签。SVG 事件定位和泳道按钮共享该 ID；日期位置按时间映射。事件切换不应改数据路径。当前演示只有手术时点/事件标签，不表示临床疗程。动画重播入口及 reduced-motion 终态已进入原型；本机探针确认 pathLength=1、动画起始 offset=1px、结束 offset=0px。

时间范围提供近 3/6/12 月与全部，窗口右端锚定档案 `today`；缩放滑杆按所选窗口占比调整左边界。切换窗口仍按全期 min/max 归一化。

## 4. 指标翻面卡

固定高度 194px；正面显示最近值、单位、日期、方法、机构、来源、记录数；背面显示本指标迷你趋势和来源提示。每卡使用独立 key 记录状态，原型只切换卡片 class、aria-pressed 和 inert，不重绘整页；本地浏览器确认几何和 scrollY 稳定。单点文案与首末日期已补；卡片背面数据按合成样例显示，不可据此签过 R1–R12。
