# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：睾丸癌确诊后与随访期的青年患者本人（15–45 岁为主），以及陪同就诊的家属；仅做信息整理与就诊准备，不做诊断与治疗建议

场景：根治性睾丸切除术后：按医生方案随访血清标志物（AFP/hCG/LDH）、监测节点（影像/化验）与生育力保存事项；就诊前把散落的报告与问题整理成可带的清单

核心流程：
1. 进入工作台先看到当前随访状态总览（距下次节点天数、医生方案原话、今日待办）
2. 录入或核对本次化验/影像结果与医生原话，AI 候选协助整理报告字段，逐项核对后入库
3. 随时间回顾标志物趋势与节点完成情况，导出就诊清单与档案摘要

完成结果：患者能在就诊前用一份可导出的清单讲清「我做了哪些检查、指标变化如何、我想问什么」，全程不生成任何判读

初始布局选择：business-first
