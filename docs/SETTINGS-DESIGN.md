# 工作台设置设计 v0.2.4

状态：本机实现说明。入口为顶栏右侧设置齿轮，包含工作区、文档解析（MinerU）、临床数据库三个 Tab。

## 当前实现

- 工作区：显示本机服务返回的资料目录状态，调用已注入的原生 `uiWorkspace.pickDirectory()` 选择目录并校验。取消和失败保留原目录；选择结果写回固定启动目录，重开后继续使用；顶栏不重复放置资料目录按钮。
- MinerU：通过本机 `/api/testicular/api/settings/mineru` 保存、查询配置状态或清除 Token。默认写入 `~/.testipal/secrets/mineru.json`，密钥文件权限 600，目录权限 700；可用 `TESTIPAL_MINERU_SECRET` 指定文件。界面只显示来源、掩码和位置；提示未来解析文档会通过 MinerU API 上传至第三方服务，建议先脱敏。保存 Token 不受未来上传确认限制；当前未接入实际文档解析或上传。
- 临床数据库：通过本机服务按需读取 ClinicalTrials.gov 官方公开登记 API；固定检索词 `testicular cancer`，最多检查最近更新的 100 条，以标题或条件关键词机械筛选最多 20 条，并展示原始登记链接。旧快照的 FAILED 是历史状态，不参与当前查询。结果未经临床相关性审核，不作个体匹配。
- 临床研究主页面也使用同一官方公开查询；官方接口失败时显示失败原因，不把失败当作零结果。患者档案不发送给官方接口。
