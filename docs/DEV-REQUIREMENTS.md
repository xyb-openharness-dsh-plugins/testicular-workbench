# DEV-REQUIREMENTS · testicular-workbench

> 状态：M0 建立基线（2026-11-14 夜班）。每条需求带「来源 + 验收 + 适用语境」；无人值守默认值见 §五。

## §一 硬红线（违反=返工）

1. **无判读列/无判定文案**：全库与全站不出现 diagnosis/risk_level/stage 列、复发判定、用药建议、治愈率、匹配指数类表述。分期与 S 分期只以医生原话照录呈现。验收：check-schema-words + check-wording + 探针禁词扫描 0 命中。
2. **私密三出口**：看板摘要预览、导出、AI 上下文三处均过滤 is_private=1；「由私密记录改写的问题同样算私密」。页内可见「N 条中私密 M 条」。验收：test/subjects-cycle 断言 + M2 探针。
3. **候选纪律**：导入候选（candidates.in_use=0）不参与任何呈现、匹配、导出；核对后才采用。验收：读模型单测 + M2 探针。
4. **演示唯一源**：页面不写死数字；两套合成档案来自 demo/ 单一来源，服务端种子读同一份；改动 demo 一个值，看板/指标页/导出三处同步。验收：M2 探针 demo 唯一源抽查。
5. **医学阈值一律【待核】**：参考范围、半衰期（AFP 5–7 天、hCG 24–36h 为常识口径）只作展示参考标注，不入库、不判定、写【待核】+「以医生安排为准」。验收：check-wording 断言。
6. **改包必升版**：版本四处同源（VERSION/package.json/lib/version.js/客户端注入）；CHANGELOG 只增不删。

## §二 患者视角红线

- 每条功能线挂患者原话或场景（USER-RESEARCH 证据分层）；无一手引语时声明 0 访谈，改写句不冒充引语。
- 界面不替医生说话：紧急口径只呈现医生已确认原话，或空态引导「需要问你的医生」。
- 功能按患者关心的信息维度组织（标志物趋势、节点完成、生育力保存、就诊准备），医生任务不冒充患者需求。

## §三 家族契约（沿用，出处见编号文档）

- 前端：页脚贴底、[hidden]、字号 12.5–15（大字档只放大字号）、面板 25–45% 可拖可收、无判读列、卡片定高 194±1px、真 3D 翻转五条（32 号）、AI 入口唯一顶栏序（Q 断言）。
- 数据层：ORDER BY rowid、显式 null、in_use、分节 section_titles、分类不进趋势、演示唯一源。
- 响应式 30 号九条；A 家族面板 40 号 7–14；整页视图 32 号 A1–A10；疾病概要 36 号 P1–P9。
