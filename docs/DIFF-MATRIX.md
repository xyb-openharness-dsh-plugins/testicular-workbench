## §二 与家族既有仓的语义隔离

| 对照仓 | 重叠风险 | 隔离措施 |
| --- | --- | --- |
| pericarditis（心包炎，移植源） | 服务层结构同形 | 结构移植 + 病种语义逐项重写；发作—缓解语义（flap_events/缓解第 N 天）全部替换为监测节点/标志物语义；残留 grep 0 |
| breast-cancer（乳腺癌，视觉基准） | 肿瘤分期/治疗线/标志物 | 结构与元素体系照抄（hero/五 Tab/眉题/折叠卡）；语义=睾丸癌（标志物三线、青年人群、生育力线）；不抄分期数值与治疗推荐文案 |
| aml（白血病，结构基准） | 血液肿瘤语义 | 只抄导航分组与心智负担组织方式；血象指标仅作化疗骨髓抑制监测记录，不抄 MRD/粒缺判定语义 |
| GTN 小葡宝 | 同生殖细胞谱系 | 人群（男性 vs 妊娠女性）、标志物组合（三线 vs 单 hCG）、部位、随访节奏完全不同 |
| 泌尿族三仓 | 同族器官 | 人群/病程/核心随访物完全不同（已写进认领 issue） |

## §三 一级重名率实测（M1 完成）

- 方法：对 breast v0.4 一级导航逐项与本台 9 页对照，逐字重名计 1、同义改名计 0.5；重名率 = 重名项 / 本台一级页数。
- 实测：M1 后回填（目标 ≤70%）。
